# Азбука вкуса — моделирование ценовых стратегий

Готовое тестовое задание: сравнение следования ценам конкурента при неизменном объёме продаж и при реакции спроса через эластичность. В расчёте 16 обезличенных товаров.

МД снижается на 41,23% и 35,08%. Рост ожидаемого объёма на 15,69% не компенсирует снижение дохода на единицу. Автоматическое следование всем минимальным ценам конкурента не рекомендуется. Главный источник потерь — ТОВАР7.

## Методика

Новая цена — минимальная положительная регулярная/промо цена конкурента. Без мониторинга сохраняется текущая цена. Мониторинг покрывает 8 из 16 товаров и 79,78% исходного ТО.

В оптимистичном сценарии `Q1=Q0*MAX(0;1-E*(P1/P0-1))`, где E — модуль эластичности. Это явное допущение: функциональная форма в ТЗ не указана. Пессимистичный сценарий сохраняет Q0. Закупка неизменна. Расчёт с НДС соответствует базе исходного кейса.

Целевой объём для сохранения МД — `ROUNDUP(МД0/(P1-c);0)` при положительном доходе с единицы. Это восстановление исходного МД, а не окупаемость постоянных расходов. МД не является чистой прибылью.

## Файлы и воспроизведение

[Скачать полный проект с исходным кодом и проверками](azbuka-vkusa-solution.zip). Распакуйте архив, чтобы выполнить команды ниже. Пути далее указаны внутри архива.

`data/items.json` и `items.csv` содержат одинаковый очищенный срез. `src/build.mjs` создаёт Excel из JSON с помощью Node.js и `@oai/artifact-tool`. Для сборки:

```sh
npm install --no-save @oai/artifact-tool
python -m pip install openpyxl
node src/build.mjs
python src/verify.py
```

Папки `outputs` и `qa` включены в проект. `src/verify.py` задаёт нулевое начало осей диаграмм в OOXML и проверяет сохранённый файл. Проверочные ожидания лежат в `qa/expected.json`, результаты сверки — в `qa/verification.json` и `qa/export-verification.json`. Скрипт `src/extract.py` позволяет заново извлечь данные из локального оригинала в родительской папке и пересчитать независимые ожидания. Оригинальная книга не публикуется: её скрытые листы содержат другие выгрузки, не требующиеся для решения кейса.

Проверены итоги по независимому расчёту, отсутствие ошибок формул и реакция на изменение входной цены. Книга рассчитана в Artifact Tool; настольный Excel отдельно не использовался для проверки пересчёта.
